# ChemAI: Predict the Cure

**Команда 1 — Ястребы**

Предсказание биологической активности химических соединений против вируса гриппа.

## Описание задачи

Для каждого из 250 соединений тестовой выборки необходимо предсказать:
- **IC50 (mM)** — концентрация подавления 50% вирусной активности
- **CC50 (mM)** — концентрация токсичности для 50% клеток
- **SI** — индекс селективности (SI = CC50 / IC50)

Метрика: среднее RMSE по трём таргетам (чем меньше, тем лучше).

## Описание подхода

### Ключевые инсайты

1. **SI = CC50 / IC50 точно** во всех 751 обучающих примерах.  
   В логарифмическом пространстве: `log(SI) = log(CC50) − log(IC50)`.  
   SI предсказывается двумя способами и объединяется бленд.

2. **Таргеты логнормально распределены** — IC50 варьируется от 0.003 до 4095 mM (>6 порядков).  
   Логарифмическая трансформация критична для качества моделей.

3. **Стекинг для SI**: OOF-предсказания log(IC50) и log(CC50) добавляются  
   как дополнительные признаки в модель SI.

### Что пробовали и что сработало

| Подход | Результат |
|--------|-----------|
| Ансамбль LGB+XGB+CAT vs одна модель | +10–15% по RMSE в пользу ансамбля |
| Optuna для LGB (50 trials) | Значимо лучше дефолтных параметров |
| Optuna для XGB (40 trials) | Умеренное улучшение |
| SI: формула CC50/IC50 vs прямая модель | Бленд (50/50) лучше обоих по отдельности |
| Стекинг OOF IC50/CC50 → SI | Небольшое улучшение |
| Bias correction exp(σ²/2) | Раздувает медианы в 3-4x — не используем |
| Удаление коррелированных признаков (r>0.95) | Уменьшает шум |

### Пайплайн

```
train.csv / test.csv
  → Препроцессинг (notebooks/solution.ipynb, ячейка 3):
      - Удаление 18 константных признаков
      - Заполнение пропусков медианой (fit только на train)
      - Добавление log-дескрипторов
      - Удаление коррелированных признаков (r > 0.95)
  → log-трансформация таргетов (np.log)
  → IC50: Optuna LGB + Optuna XGB + CatBoost (5-fold CV)
  → CC50: Optuna LGB + Optuna XGB + CatBoost (5-fold CV)
  → SI: OOF IC50/CC50 как признаки + Optuna LGB + XGB + CAT
  → SI бленд: 50% прямая модель + 50% формула CC50/IC50
  → Взвешенный ансамбль (вес ∝ 1/OOF-RMSE)
  → np.exp() → submission.csv
```

## Воспроизведение результатов

### Установка зависимостей

```bash
python -m venv .venv
.venv\Scripts\activate      # Windows
# source .venv/bin/activate  # для Linux/macOS
pip install -r requirements.txt
```

### Запуск

```bash
jupyter notebook notebooks/solution.ipynb
```

Запустить все ячейки сверху вниз (Kernel → Restart & Run All).  
Submission сохраняется в `submissions/submission.csv`.

### Ключевые параметры (ячейка 1 ноутбука)

```python
SEED              = 42   # фиксированный seed для воспроизводимости
N_FOLDS           = 5    # количество фолдов
OPTUNA_TRIALS_LGB = 50   # число попыток Optuna для LightGBM
OPTUNA_TRIALS_XGB = 40   # число попыток Optuna для XGBoost
USE_OPTUNA        = True # включить/выключить оптимизацию
CORR_THRESHOLD    = 0.95 # порог корреляции для удаления признаков
```
